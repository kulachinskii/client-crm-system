# Client CRM System

Информационная система автоматизации взаимодействия с клиентами
от первого касания до заключения договора.

## Основные функции

- регистрация клиентов;
- хранение контактных данных;
- учет взаимодействий с клиентами;
- ведение сделок;
- контроль этапов сделки;
- учет заключенных договоров.
